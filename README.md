# Chair images

Images exported from the `Стулья (2).xlsx` source workbook for an educational furniture comparison.

Each `images/chair-row-XXXX-NN.png` file is linked to the same Excel row number. Direct image URLs follow:

`https://raw.githubusercontent.com/lxstjxck/chair-images/main/images/chair-row-0004-01.png`

The repository is currently private; to make public image links work for anyone, change **Settings → General → Danger Zone → Change repository visibility → Public** and push the `images/` directory.

Images may be subject to third-party copyright. Retain attribution to original sources and verify reuse rights before public distribution.
