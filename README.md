# Chair images

Public repository for images exported from the `Стулья (2).xlsx` workbook.

The `images/` directory is uploaded using the `Загрузить_фото_на_GitHub.cmd` script from the prepared ZIP package. `manifest.csv` maps every image to the corresponding Excel row and image URL.

**Direct URL example (available after upload):**

`https://raw.githubusercontent.com/lxstjxck/chair-images/main/images/chair-row-0004-01.png`

Image filenames are keyed by original Excel row numbers (`chair-row-XXXX-NN.ext`). In the updated workbook, column E contains the direct URLs. Where two photographs belong to a model, both links are present.

Only upload photos that you have the right to redistribute. The original third-party images may be subject to copyright.
